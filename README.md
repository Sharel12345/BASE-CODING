# Unifight Taekwondo Club – אתר המועדון

אתר סטטי (HTML/CSS/JS) למועדון הטאקוונדו יוניפייט, חיפה.

- `index.html` – העמוד
- `styles.css` – עיצוב
- `script.js` – תפריט מובייל, אנימציות גלילה, טופס לוואטסאפ
- `assets/logo.jpg` – לוגו

הרצה מקומית: לפתוח את `index.html` בדפדפן. אפשר להעלות כמו שזה ל-GitHub Pages / Netlify / Vercel.
